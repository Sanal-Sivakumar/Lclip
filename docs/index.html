Refined Glassmorphism.

Everything in one floating glass pane. We've crafted a premium, highly translucent dark mode that seamlessly blends with your wallpaper.

  • Clean Interface: Search bar is decluttered by removing shortcut hints. The LClip logo is now clickable, taking you straight back to your history.
  • Context Aware: Clipboard history now displays the exact source application (like VS Code or Firefox) and the precise time you copied it.
  • Translucent Depth: A lighter, more translucent backdrop inspired by premium modern OS designs.

Express yourself faster.

An extensive, categorized offline library of expressions, completely redesigned for a premium selection experience.

  • Immersive Grid: Now featuring exactly 9 emojis per row, with text labels removed for a cleaner, high-density look.
  • Minimal Navigation: Tabs (History, Emoji, Symbols, Kaomoji) are now icon-only and spaced elegantly away from the logo.
  • Fast Keyboard Workflow: Search, arrow navigation, and Enter to paste without lifting a finger.

Privacy & Desktop Integration First

LClip is not a keylogger. It registers one explicit global chord and keeps clipboard history local, bounded, and secure. It degrades gracefully on strict Wayland security policies while attempting the best input bridge (ydotool, wtype, or xdotool).
