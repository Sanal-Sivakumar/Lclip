Designed for the desktop you have

Copy. Open. Select. Continue.

01

Keep a small local history

Ten text entries, deduplicated and timestamped, with no hidden keystroke capture or cloud account required.

02

Find the right expression

Search offline emoji, kaomoji, and symbols without leaving the app you are working in. GIF search remains optional and uses your own GIPHY key.

03

Paste with a safe fallback

LClip copies first, then uses the available Linux input bridge. If your desktop rejects synthetic input, the value remains on the clipboard for normal Ctrl + V.

Transparent about permissions

Linux integration without hidden behavior.

LClip registers only Super + .; it is not a keylogger. GNOME, KDE, X11, and Wayland differ in what they permit, so Settings and the release documentation keep shortcut, paste, and storage states separate.
